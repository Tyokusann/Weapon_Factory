# 2DクラフトアクションRPG 基本仕様（初版）

## 1. 目的
READMEに記載された企画内容を、実装開始できるレベルの「基本仕様」に落とし込む。
本書はMVP（最小実装版）の開発着手と、作業分担・見積もりの基準として利用する。

## 2. 対象プラットフォーム・技術
- 実行環境：PC向けWebブラウザ
- 公開形態：GitHub Pages等の静的ホスティングで公開可能
- 推奨技術：TypeScript + Phaser 3

## 3. ゲーム概要
- ジャンル：2Dドット絵風クラフトアクションRPG
- コアループ：探索 → 素材収集 → 戦闘 → 帰還 → クラフト/強化 → 次エリア解放
- 初期体験ゴール：
  - 森マップで素材を集める
  - 木の剣をクラフトする
  - スライムを倒せる

## 4. MVPスコープ

### 4.1 実装対象（In Scope）
1. プレイヤー移動（8方向または4方向）
2. フィールド1マップ（森）
3. 素材採取（最低1種）
4. 敵1種類（スライム）
5. 通常攻撃
6. HP管理（プレイヤー/敵）
7. 武器1種類（木の剣）
8. クラフト1レシピ（木の剣）
9. インベントリ（素材・武器）
10. ブラウザでの起動と静的公開可能構成

### 4.2 非対象（Out of Scope）
- 複数マップ遷移
- 武器強化分岐（+1, 属性付与）
- ショップ/クエスト/セーブ
- 複数敵AI・ボス
- 本格的なストーリー演出

## 5. 画面仕様

### 5.1 タイトル画面
- 表示内容：ゲームタイトル、開始ボタン
- 入力：Enterキーまたはクリックで開始

### 5.2 フィールド画面（森）
- 表示要素：
  - プレイヤー
  - 敵（スライム）
  - 採取ポイント
  - 簡易UI（HP、所持素材数、装備武器）
- 遷移：
  - Cキーでクラフト画面へ
  - Escキーでフィールドに戻る（クラフト画面から）

### 5.3 クラフト画面
- 表示内容：
  - 作成可能レシピ（木の剣）
  - 必要素材 / 所持素材
  - 作成可否
- 操作：
  - 決定キー（Enter）でクラフト
  - 終了キー（Esc）で戻る

## 6. 入力仕様（初期）
- 移動：WASD / 矢印キー
- 攻撃：Space
- 調べる・拾う：E
- インベントリ開閉：I（MVPでは簡易表示でも可）
- クラフト画面：C

## 7. ゲームオブジェクト仕様

### 7.1 プレイヤー
- ステータス：HP、移動速度、攻撃力
- 行動：移動、攻撃、採取、被弾
- 失敗条件：HPが0でゲームオーバー（仮実装可）

### 7.2 敵（スライム）
- ステータス：HP、接触ダメージ
- 行動：プレイヤー追跡または単純巡回
- 撃破時：確率または固定で素材ドロップ

### 7.3 素材
- MVP素材候補：木材、スライムゼリー
- 入手経路：採取ポイント・敵ドロップ
- 役割：クラフト材料

### 7.4 武器（木の剣）
- 種別：近接武器（剣）
- パラメータ（MVP）：攻撃力、攻撃速度（固定値）
- 入手方法：クラフトのみ

## 8. システム仕様

### 8.1 戦闘システム
- リアルタイム2Dアクション
- 攻撃判定：前方短距離の当たり判定
- ダメージ計算（簡易）：
  - 与ダメージ = 武器攻撃力（固定）
  - 被ダメージ = 敵接触ダメージ（固定）

### 8.2 採取システム
- 採取ポイントに接近しEキーで採取
- 採取後クールタイムまたは消滅（MVPは消滅推奨）

### 8.3 インベントリシステム
- 管理カテゴリ：素材、武器
- MVP要件：
  - 素材個数の増減
  - 武器所持判定（木の剣の有無）

### 8.4 クラフトシステム
- レシピ例：木材 x3 + スライムゼリー x1 → 木の剣
- 作成条件：必要素材を満たす
- 作成結果：素材消費・木の剣を追加

## 9. データ仕様（JSON想定）

### 9.1 materials.json
- id
- name
- description
- stackable

### 9.2 weapons.json
- id
- name
- attack
- attackSpeed
- range

### 9.3 recipes.json
- id
- resultItemId
- resultCount
- materials[]（materialId, count）

### 9.4 enemies.json
- id
- name
- hp
- contactDamage
- dropTable[]

## 10. シーン構成（Phaser想定）
- BootScene：アセット読み込み
- TitleScene：開始画面
- FieldScene：探索・戦闘・採取
- CraftScene：クラフト

## 11. 受け入れ条件（Definition of Done）
1. ローカルで `npm run dev` によりゲームが起動する
2. タイトルから開始して森フィールドへ遷移できる
3. プレイヤーが移動・攻撃できる
4. 採取で素材を取得できる
5. スライムを倒せる
6. クラフト画面で木の剣を作成できる
7. 木の剣作成後に戦闘効率が上がる（攻撃力差が確認できる）
8. `npm run build` が成功し、静的ホスティング可能な成果物を生成できる

## 12. 実装優先順位
1. プロジェクト雛形（Phaser + TypeScript）
2. FieldSceneで移動・当たり判定
3. 敵（スライム）とHP処理
4. 採取とインベントリ
5. クラフトUIとレシピ適用
6. 最低限のUI調整・公開設定
