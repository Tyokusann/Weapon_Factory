# 2DクラフトアクションRPG 仕様書

## 1. コンセプト

ドット絵風の可愛いキャラクターを操作し、マップ探索で素材を集め、武器をクラフト・強化しながらダンジョンの奥へ進む2DアクションRPG。

参考イメージ：
- サモンナイト クラフトソード物語系
- 探索
- 素材収集
- 武器制作
- 武器強化
- 2Dアクション戦闘

## 2. 対応環境

- Webブラウザで起動できるゲーム
- GitHubリポジトリに投稿して管理する
- GitHub Pages、Vercel、Netlifyなどで公開可能な構成にする

## 3. 推奨技術

### フロントエンド
- HTML
- CSS
- JavaScript / TypeScript

### ゲームエンジン候補
- Phaser 3

理由：
- Webブラウザ向け2Dゲームに強い
- ドット絵ゲームと相性がよい
- GitHub Pagesで公開しやすい

## 4. ゲームジャンル

2Dドット絵風クラフトアクションRPG

## 5. ゲームの基本ループ

1. 拠点からマップへ出発する
2. マップを探索する
3. 木材・鉱石・魔石などの素材を集める
4. 敵とアクション戦闘をする
5. 素材を持ち帰る
6. 武器を作る・強化する
7. より奥のマップへ進む
8. 強敵・ボスを倒す

## 6. プレイヤーキャラクター

### 見た目
- とにかく可愛い
- 2D
- ドット絵風
- 小さめの頭身
- 表情がわかるデザイン

### 操作
- 移動
- 攻撃
- 回避
- アイテム取得
- メニュー操作
- クラフト操作

## 7. 戦闘システム

### 基本
- リアルタイム2Dアクション
- 武器ごとに攻撃範囲・速度・威力が異なる
- 敵の攻撃を避けながら戦う

### 操作案
- 矢印キー / WASD：移動
- Space：攻撃
- Shift：回避
- E：調べる・拾う
- I：インベントリ
- C：クラフト画面

## 8. 武器システム

### 武器カテゴリ
- 剣：標準性能
- 斧：高威力・遅い
- 槍：リーチが長い
- ハンマー：鉱石採取にも使える
- 杖：魔法攻撃

### 武器パラメータ
- 攻撃力
- 攻撃速度
- リーチ
- 耐久値
- 属性
- 強化レベル

### 強化
素材を消費して武器を強化する。

例：
- 鉄の剣 + 鉄鉱石 ×3 → 鉄の剣+1
- 鉄の剣+1 + 魔石 ×1 → 火属性の鉄剣
