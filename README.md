# Weapon Factory (MVP)

2DクラフトアクションRPGのMVP実装です。TypeScript + Phaser 3 + Viteで構成しています。

## 現在の実装範囲

- タイトル画面（Enter/クリックで開始）
- 森フィールド1マップ
- プレイヤー移動（WASD / 矢印）
- 攻撃（Space）
- 素材採取（Eで木材）
- 敵1種類（スライム）
- HP表示と被ダメージ
- クラフト画面（Cで遷移）
- 木の剣レシピ（木材x3 + スライムゼリーx1）

## 開発コマンド

```bash
npm install
npm run dev
npm run build
```

## 操作方法

- 移動: `WASD` または `矢印キー`
- 攻撃: `Space`
- 採取: `E`
- クラフト画面: `C`
- クラフト画面から戻る: `Esc` または `C`
